# FallGuard Data Directory

This directory manages dataset inputs, extracted kinematic landmarks, and engineered feature matrices for training and evaluating FallGuard models.

> [!IMPORTANT]
> **Strict Privacy & Git Tracking**:  
> The entire `data/` directory (except for `.gitkeep` placeholders and documentation) is strictly ignored by `.gitignore`. Raw video frames, sequence images, landmarks, and engineered datasets must never be committed to source control or uploaded to public repositories.

## Dataset Annotation & Label Scheme

Ground truth labels in the benchmark datasets follow the standard 3-tier posture state encoding:

| Label Value | Posture State | Description |
| :---: | :--- | :--- |
| **`-1`** | **Not Lying** | Standing, walking, reaching, sitting down, picking up objects, or normal daily activities. |
| **`0`** | **Falling / Transition** | Rapid descent or uncontrolled trajectory from an upright posture toward the ground. |
| **`1`** | **Lying Down** | Incapacitated or resting on the floor following a fall, or lying down on a bed/mat during specific ADLs. |

### Fall Keyframe Detection
- `fall_start_frame`: The first frame in a sequence labeled `0`.
- `fall_end_frame`: The first subsequent frame labeled `1` (marking complete impact/lying state).
- `has_lying_adl`: Flags Activities of Daily Living (ADLs) that contain intentional lying postures (label `1`), providing essential hard-negative cases for training robust false-alarm rejection.

## Generating the Master Catalog (`data/videos.csv`)

To index raw datasets and build the unified catalog:

```powershell
python src/prepare_datasets.py
```

The script scans `data/raw/urfd/` (handling existing subfolders dynamically) and checks for optional custom clips in `data/own_clips.csv`. It outputs `data/videos.csv` with the following columns:

- `video_id`: Sequence identifier (e.g. `fall-01`, `adl-01`)
- `dataset`: Source dataset (`urfd`, `own`)
- `path`: Path to image folder or video file
- `label`: Binary high-level class (`fall`, `adl`)
- `fps`: Capture frame rate (30.0 for URFD)
- `n_frames`: Number of frames in the sequence
- `fall_start_frame`: First frame of fall descent (empty for ADLs)
- `fall_end_frame`: First frame of resting floor posture (empty for ADLs)
- `has_lying_adl`: Boolean indicating whether an ADL includes floor/bed lying

## Benchmark Datasets Reference & Search Terms

When searching for, acquiring, or citing academic fall detection datasets, use the following official academic search terms:

1. **UR Fall Detection Dataset (URFD)**
   - *Search term*: `"UR Fall Detection Dataset" University of Rzeszow`
   - Contains RGB and depth camera streams capturing acted falls and diverse daily living activities.

2. **Multiple Cameras Fall Dataset**
   - *Search term*: `"Multiple Cameras Fall Dataset"`
   - Multi-camera synchronized setup capturing falls and complex activities from multiple perspective angles.

3. **Le2i Fall Detection Dataset**
   - *Search term*: `"Le2i Fall Detection Dataset"`
   - Diverse realistic room environments (living room, bedroom, office, corridor) with varied lighting and occlusions.

4. **SisFall Dataset**
   - *Search term*: `"SisFall Dataset: A Fall and Movement Dataset"`
   - Comprehensive benchmark dataset featuring elderly and young participants performing ADLs and simulated falls.
