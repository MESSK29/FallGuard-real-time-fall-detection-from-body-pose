How FallGuard Works in 4 Steps

From optical sensor to validated emergency alert, every step is designed for high speed, zero video leaks, and minimized false alarms.

1

Camera Feed

Standard local camera captures raw video in volatile RAM. Frames are immediately handed to the on-device pose estimator and purged.

Zero footage saved
2

Pose Skeleton

MediaPipe Pose extracts 33 key landmark coordinates on CPU. We compute torso angles, hip heights, and vertical speeds normalized by torso length.

Pure coordinate data
3

AI Classifier

Machine learning models (Random Forest & XGBoost) continuously analyze 2-second sliding temporal windows (min, max, mean, delta) using a shared features.py.

Temporal dynamics
4

Verified Alert

A potential fall triggers a 2-second verification countdown. The alert is confirmed only if the person remains lying still, preventing false alarms from drops or sitting.

Two-stage validation
Core Capabilities

Built for Real-World Care & Dignity

Engineered specifically to balance sensitive elderly privacy with dependable, low-latency fall detection.

Privacy-By-Design

Elderly care requires absolute personal dignity. In FallGuard, raw video never touches disk, cloud servers, or external databases. Telemetry is strictly numerical.

Runs on Standard Laptop CPU

No expensive GPUs, specialized TPUs, or high-power server racks required. Runs smoothly in Python 3.10/3.11 on standard budget hardware.

Two-Stage Confirmation

Eliminates the nuisance of false positives. When the classifier suspects a fall, it checks for a ~2-second subsequent "lying still" state before sending alerts.

Single Shared Pipeline

Feature calculations are centralized in a unified features.py module. Offline training and online real-time inference share the exact same mathematical code.

Leak-Free GroupKFold

Machine learning models are validated strictly grouped by video subject. Temporal sliding windows never contaminate validation folds.

Explainable AI with SHAP

We inspect what kinematic signals drove the decision—whether vertical hip velocity, aspect ratio collapse, or torso angle change.
